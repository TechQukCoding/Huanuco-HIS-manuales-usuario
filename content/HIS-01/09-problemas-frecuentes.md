# 9. Problemas frecuentes

| Situación o mensaje | Causa | Qué hacer |
|---|---|---|
| *Ya existe un paciente registrado con este documento* | El paciente ya está en el directorio. | Búsquelo y abra su ficha; no lo duplique. |
| *Ingresa un DNI válido (8 dígitos)* | El DNI está incompleto. | Corrija el número. |
| No puedo cambiar el DNI de un paciente | Un paciente identificado no permite editar su DNI. | Si fue un error de digitación, consulte a soporte técnico. |
| No aparece ninguna programación para una fecha | No hay rol aprobado ese mes o la programación está inactiva. | Verifique el rol en SIGARH (SIG-02) y el estado en *Programación Médica*. |
| *Ese cupo ya está ocupado* | Otro usuario lo tomó primero. | Elija otro cupo libre y vuelva a guardar. |
| *Ese cupo ya pasó; elige un horario posterior a la hora actual* | El cupo es de una hora ya transcurrida. | Elija una hora posterior. |
| *El paciente ya tiene una cita en esta programación* | Duplicado. | Revise sus citas en *Citados*. |
| No puedo reprogramar una cita | Está atendida, cancelada o ya tiene **triaje**. | No se reprograma; registre una nueva cita si hace falta. |
| *Esta programación proviene de un rol aprobado de SIGARH…* | Intenta cambiar horario, médico o estado. | Cámbielo en el rol o con un cambio de turno (SIG-01, SIG-02). |
| Una cita muestra la etiqueta **Reprogramar** | Su médico dejó de estar programado ese día. | Reprograme la cita (capítulo 3). |
| *El turno de consultorio requiere una cita del día* | Ticket de Consultorio sin cita. | Agende primero la cita. |
| *Kiosko / Pantalla no autorizada* | Enlace revocado o perdido. | Genere un **Nuevo enlace** en Turnero › Configuración. |
| El enlace del dispositivo ya no se ve | Solo se muestra una vez. | Use **Nuevo enlace** (el anterior deja de funcionar). |
| *No hay paciente registrado con ese documento* (Turnero) | El DNI no existe. | Registre al paciente o emita sin DNI. |
| *Este destino de emergencia no corresponde a referencia* | La atención no tiene destino *Referencia*. | Revise el destino en Emergencia (HIS-03). |
| *El profesional debe tener profesión Trabajador Social (TSO) registrada* | El empleado no es TSO. | Corrija su profesión en SIGARH (SIG-01). |
