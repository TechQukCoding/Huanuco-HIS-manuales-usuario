# 7. Problemas frecuentes

| Situación o mensaje | Causa | Qué hacer |
|---|---|---|
| *Ingresa un DNI válido de 8 dígitos* | DNI incompleto. | Corrija el número. |
| *Selecciona un paciente primero* | No se eligió el paciente. | Búsquelo por DNI o regístrelo. |
| *La hora de llegada no puede ser futura* | La hora es posterior a la actual. | Corrija la hora (hora de Lima). |
| *Esta admisión ya tiene un triaje registrado* | Ya se hizo. | Use la lista para abrirlo. |
| No puedo iniciar la atención médica | Falta el triaje, o el usuario no es médico. | Registre el triaje; use la cuenta del médico (SIG-01, SIG-04). |
| *El paciente pasa a observación después del triaje* | Falta el triaje. | Regístrelo primero. |
| *La cama o sillón debe pertenecer a una sala activa tipo OBSERVACION…* | La cama no es de una sala de observación. | Elija otra cama o configure la sala (SIG-03). |
| *No hay camas libres…* | Todas están ocupadas o no existen. | Libere una cama o configure más en SIGARH (SIG-03). |
| *Registre la fuente de financiamiento de la admisión antes de emitir órdenes* | La admisión no tiene fuente de financiamiento. | Complétela con Admisión. |
| *Medicamento no encontrado o inactivo* | El medicamento no está en el catálogo o está inactivo. | Actívelo (SIG-03) o descríbalo en *O describa el medicamento*. |
| *La indicación ya está suspendida* | Ya se suspendió. | No requiere más acción. |
| *El episodio de emergencia ya está cerrado* | La atención ya terminó. | No se agregan registros tras el cierre. |
| *Las indicaciones, reevaluaciones y órdenes las registra el médico* | Quien registra no es médico. | Pida al médico. |
| *No se puede editar una atención ya firmada* | La atención se cerró con PIN. | No se modifica una atención firmada. |
| *PIN incorrecto.* / *Configura tu PIN de firma en Mi Perfil…* | PIN equivocado o no configurado. | Configúrelo en *Mi perfil* (GEN-00, sección 4.5). |
| El paciente no aparece en la cola de hospitalización | La atención no está firmada o el destino es otro. | Verifique la firma y el destino en *Atenciones* (capítulo 5). |
