# 8. Problemas frecuentes

| Situación o mensaje | Causa | Qué hacer |
|---|---|---|
| No veo una categoría en Creación de Roles | Su perfil no la incluye (*No tiene permiso para esta categoría de personal*). | Solicite el submódulo al administrador (SIG-04). |
| El botón **Crear y continuar** está deshabilitado | Faltan departamentos o servicios. | Cree o active departamento y servicio (SIG-04). |
| *Ya existe un rol médico ordinario para ese departamento, servicio y período.* | Ya hay uno para ese mes. | Abra el existente desde la lista. |
| Un empleado no aparece al agregar personal | Ya está en el rol, está inactivo, es de otro servicio o su categoría no coincide. | Revise su ficha (SIG-01): servicio, tipo de trabajador y grupo ocupacional. |
| *… ya pertenece a otro rol ordinario de este servicio para MM/AAAA.* | Está en otro rol ordinario del mismo mes. | Quítelo del otro rol o use un rol complementario. |
| No puedo enviar el rol a revisión | El diagnóstico tiene **errores**. | Corrija lo que indica el diagnóstico (capítulo 4). |
| El rol médico dice que falta la jornada o la colegiatura | La ficha del médico está incompleta. | Complete jornada mensual y sustento, colegiatura y vínculo (SIG-01). |
| *Acumula N horas ordinarias; su jornada documentada permite M…* | Se superó la jornada mensual. | Reduzca turnos o corrija la jornada documentada. |
| No puedo aprobar un rol | Faltan permisos, usted lo elaboró, o hay errores. | Ver sección 5.3. |
| *Quien elaboró el rol no puede aprobarlo…* | Separación de funciones. | Pida a otra persona con permiso que lo revise. |
| El rol aprobado no abrió cupos | Ningún turno usa una actividad que genere agenda. | Vea la advertencia del diagnóstico (sección 4.1) y use una actividad asistencial. |
| Necesito agregar a alguien a un rol ya aprobado | Un rol aprobado no se edita. | Tramite una **solicitud de incorporación** (capítulo 6). |
| *No se puede eliminar…* un rol | Solo se eliminan roles en borrador o rechazados. | Un rol enviado o aprobado no se elimina. |
