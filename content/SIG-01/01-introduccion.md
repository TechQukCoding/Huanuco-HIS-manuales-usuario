# 1. Introducción

<p class="lead">Este manual cubre el trabajo diario con el <strong>personal</strong> en SIGARH: registrar empleados, controlar su asistencia y tramitar sus justificaciones, vacaciones, licencias, cambios de turno y papeletas.</p>

## 1.1 Qué contiene

| Grupo del menú | Pantallas | Capítulo |
|---|---|---|
| **Recursos Humanos** | Empleados | 2 |
| | Especialidades, Días feriados, Motivos de justificación, Tolerancias | 3 |
| | Registro de asistencia | 4 |
| | Justificaciones e inasistencias | 5 |
| **Movimientos** | Justificación y Vacaciones | 6 |
| | Tramitar Licencia y Estado Licencia | 7 |
| | Tramitar Cambio de Turno y Estado Cambio Turno | 8 |
| | Tramitar Papeleta y Estado de Papeletas | 9 |

## 1.2 Cómo se relacionan

- Los **catálogos** de Mantenimiento (grupos ocupacionales, profesiones, servicios, dependencias, tipos de trabajador, niveles remunerativos) se cargan primero. Vea el manual **SIG-04**.
- Cada **empleado** toma de ellos sus datos laborales. Con el empleado ya registrado se le puede crear una **cuenta** (SIG-04) y programar en **roles de turno** (SIG-02).
- Los **movimientos** (vacaciones, licencias, justificaciones, cambios de turno, papeletas) se aprueban o rechazan y, al aprobarse, **actualizan la asistencia** del empleado.

## 1.3 Estados de las solicitudes

Todas las solicitudes de Movimientos siguen el mismo ciclo:

Pendiente › Aprobado, o Rechazado (con su motivo). Una vez decidida, una solicitud **no se puede decidir otra vez**. El resultado se avisa en las **Notificaciones** de SIGARH.

!!! note "Nota"
    Cada pantalla depende de un submódulo de su perfil (SIG-04). Si una opción no aparece en su menú, solicite el permiso a su administrador. Las búsquedas por **DNI** consultan el registro de Empleados del hospital, no un servicio externo.
