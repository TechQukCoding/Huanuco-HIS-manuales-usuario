# 7. Problemas frecuentes

| Situación o mensaje | Causa | Qué hacer |
|---|---|---|
| *No hay quirófanos: créelos en SIGARH…* | No existen salas de tipo Quirófano. | Créelas (SIG-03). |
| *El quirófano … ya tiene una cirugía en ese horario* | Choque de horario. | Elija otra hora o quirófano. |
| *Una misma persona no puede ocupar dos funciones en el equipo quirúrgico* | Se repite una persona. | Asigne una persona distinta a cada función. |
| El paciente no puede ingresar a sala | Faltan evaluaciones, consentimientos o anestesiólogo. | Revise *Para continuar falta…* (capítulo 3) o, en emergencia, registre la excepción. |
| *Todo ítem no cumplido requiere observación* | Falta la observación de un ítem no conforme. | Escríbala. |
| *El lote no está liberado para uso* | El material no completó su ciclo de esterilización. | Libere el lote en la Central (capítulo 5). |
| *Un implante requiere número de serie* | Falta la serie. | Escríbala. |
| *Solo el cirujano principal firma el informe operatorio* | Firma otra persona. | Firme con la cuenta del cirujano principal. |
| *Complete antes de firmar: …* | Faltan datos del informe. | Complete lo que indica el mensaje. |
| *La paciente ya tiene la atención … abierta* | Ya hay una atención obstétrica abierta. | Ábrala desde la lista (capítulo 4). |
| *Registre los controles del puerperio inmediato antes del alta* | Faltan controles. | Registre al menos uno. |
| *La unidad … venció el …; no debe usarse* | El paquete superó su vigencia. | Devuélvalo a reproceso. |
| *Hay especímenes pendientes de recepción* | Falta recibir una muestra. | Reciba o rechace cada espécimen. |
| *La cirugía no tiene una muestra enviada con informe operatorio firmado* | La pieza aún no llegó a Patología. | Firme primero el informe operatorio (capítulo 3). |
