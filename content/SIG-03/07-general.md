# 7. General: diagnósticos, paquetes y tiempos

## 7.1 Diagnósticos CIE-10

Ruta: **General › Diagnósticos CIE-10** (*Catálogo oficial MINSA de diagnósticos*). Es un catálogo **de consulta**: se busca y se ve el detalle, pero no se modifica desde esta pantalla.

- **Buscador:** *Código, diagnóstico o categoría…*, con **Limpiar búsqueda**. Si no hay coincidencias: *No se encontraron diagnósticos. Prueba con otro código o término.*
- **Tabla:** Código, Diagnóstico, Categoría y Estado (**Vigente** o **Inactivo**), con paginación.
- **Ver** abre el **Detalle del diagnóstico CIE-10**: capítulo, grupo, categoría, código CIE-9 relacionado, aplicación por sexo, edad mínima y edad máxima. Los datos no registrados se muestran como *No especificado*.

!!! note "Nota"
    Si el catálogo aparece vacío (*El catálogo está vacío*), pida a soporte técnico que cargue el catálogo oficial.

## 7.2 Paquetes

Ruta: **General › Paquetes** (*Paquetes de procedimientos y servicios*). Indicadores: Paquetes, Activos, Inactivos y Precio promedio (S/). Tabla: Nombre, Código, Precio total (S/.) y Estado.

| Campo | Descripción |
|---|---|
| Nombre del paquete | Ej.: *Paquete de parto normal*. |
| Código | Opcional; identifica el paquete en reportes. |
| Precio total (S/.) | En soles. |
| Descripción | Procedimientos y servicios que incluye. |
| Activo | Los paquetes inactivos **no se ofrecen al registrar atenciones**, pero se conserva su historial. |

!!! tip "Consejo"
    Describa en el paquete todo lo que incluye, para que Caja y las áreas clínicas lo identifiquen sin dudas.

## 7.3 Tiempos de procedimientos

Ruta: **General › Tiempos Procedimientos** (*Duración estándar por tipo de procedimiento*). Indicadores: Procedimientos, Activos, Con especialidad y Duración promedio. Tabla: Nombre, Código, Especialidad, Duración y Estado.

| Campo | Descripción |
|---|---|
| Nombre del procedimiento | Ej.: *Ecografía obstétrica*. |
| Código | Opcional. Se usa para que Caja encuentre la tarifa de un procedimiento (capítulo 5). |
| Duración (minutos) | En **múltiplos de 5 minutos**. |
| Especialidad | Sin especialidad, el tiempo aplica a **cualquier servicio**. |
| Activo | Solo los activos se usan como duración estándar. |

!!! tip "Consejo"
    Use el tiempo real promedio del procedimiento: sirve para planificar la agenda y los turnos.
